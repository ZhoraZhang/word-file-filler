# word文档填充小工具
随手写的一个word文档填充小工具

# 运行
方法1：
运行word_filler_gui.py

方法2：
运行word文档填充器.exe

#使用
1. 在word模板需要填充的地方写入{{填入项名称}} （记得加{}或者{{}}，填入项名称不可重复），可提前设置好格式；
2. 在excel中第一行填入 填入项名称 （去掉{}和{{}}），第二行以及之后的行里填入对应项的内容 （多于两行可自动批量填充）；
3. 运行word文档填充器.exe，选择输入的word模板，输入的excel文件，输出路径（输出路径默认当前路径+output_reports\xxx.docx；
4. 点击生成
